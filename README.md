# 🍛 Dastarkhwan — A Taste of Home

**Dastarkhwan** is an interactive landing page celebrating Pakistani comfort food and the memories connected to it.

Some meals do more than fill you up. They take you home. ❤️

Built for the **DEV Community Frontend Challenge: Comfort Food Edition — Perfect Landing**.

## 🌐 Live Demo

[**Explore Dastarkhwan →**](https://dastarkhwan-azure.vercel.app/)

## ✨ Features

* **Mood-Based Dish Selector:** Choose how you're feeling and discover a comfort dish that matches your craving.
* **Pakistani Comfort Food Collection:** Explore Biryani, Nihari, Daal Chawal, and Paratha & Chai.
* **Warm, Nostalgic Design:** An inviting visual experience inspired by Pakistani food and the feeling of home.
* **Responsive Layout:** Designed to provide a comfortable browsing experience across different screen sizes.
* **Smooth Interactions:** Enjoy animated transitions, interactive elements, and smooth navigation.
* **Accessibility Considerations:** Semantic HTML, descriptive image text, and accessible interaction states.

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
4. Explore the page and try selecting different moods to discover the recommended dishes.

No package installation or build step is required.

## 🎯 Project Goal

The goal was to create more than a typical restaurant landing page. Dastarkhwan celebrates the connection between food, family, memories, and home through a warm visual design and a simple interactive experience.
